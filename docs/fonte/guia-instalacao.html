Guia de instalação em outro computador

Como preparar qualquer notebook com Windows para rodar o sistema completo (banco de dados, API, painel e leitura do Arduino) e ligá-lo com dois cliques no dia da feira.

Versão do sistema: API v3.1.0 • Painel v3.0.1  |  Repositórios: github.com/Pedroakkaka/HydraSmartAPI e HydraSmartFront
1 · Instalar programasGit, Node.js e Docker Desktop (uma vez)
2 · Instalar o sistemagit clone + dois cliques em INSTALAR
3 · UsarDois cliques em INICIAR e PARAR
Faça a instalação com antecedência e com internet. No dia da feira só é preciso ligar o sistema.

O que o notebook precisa ter

ItemMínimo
SistemaWindows 10 (22H2) ou Windows 11, 64 bits
Memória8 GB de RAM (o Docker usa cerca de 2 GB)
Espaço livre10 GB
VirtualizaçãoAtivada na BIOS (quase todos os notebooks já vêm assim)
Porta USBPara o cabo do Arduino
Para conferir a virtualização: abra o Gerenciador de Tarefas → Desempenho → CPU e veja se "Virtualização" mostra Habilitado.

Instalação (uma vez por computador)

1

Instalar os programas

~20 min

Instale nesta ordem, sempre aceitando as opções padrão:

  1. Git — git-scm.com/download/win
  2. Node.js (versão LTS) — nodejs.org
  3. Docker Desktop — docker.com/products/docker-desktop
    • Na instalação, deixe marcado "Use WSL 2".
    • Reinicie o computador quando ele pedir.
    • Abra o Docker Desktop uma vez, aceite os termos e espere aparecer "Engine running" no canto inferior esquerdo. O login pode ser pulado.
    • Recomendado: em Settings → General, marque "Start Docker Desktop when you sign in".
  4. Driver do Arduino, só se a placa for um modelo compatível com chip CH340 (os mais baratos): wch-ic.com/downloads/CH341SER_EXE.html
Se o Docker reclamar de WSL: abra o PowerShell como administrador, rode wsl --update e reinicie.
2

Baixar o projeto

~1 min
  1. Crie a pasta C:\HydraSmart.
  2. Clique com o botão direito dentro dela e escolha "Abrir no Terminal".
  3. Rode o comando:
git clone https://github.com/Pedroakkaka/HydraSmartAPI.git

Se o GitHub pedir login, entre com uma conta que tenha acesso aos repositórios. O painel (HydraSmartFront) é baixado sozinho no próximo passo.

3

Instalar o sistema

1 a 5 min

Abra a pasta C:\HydraSmart\HydraSmartAPI e dê dois cliques em:

INSTALAR-HYDRASMART.bat

O instalador faz tudo sozinho:

  • confere se Node, Git e Docker estão instalados;
  • baixa o painel (HydraSmartFront);
  • cria o arquivo de configuração .env;
  • instala as dependências;
  • liga o banco de dados e cria as tabelas;
  • gera o painel otimizado e roda os testes.

Estrutura final das pastas:

C:\HydraSmart\
├── HydraSmartAPI\    servidor, banco e
│                     atalhos (.bat)
└── HydraSmartFront\  painel
No final deve aparecer "Instalação concluída!".
Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo.

Uso no dia a dia

4

Ligar o sistema

~30 s
  1. Ligue o Arduino no USB.
  2. Feche a IDE do Arduino, se estiver aberta. Ela prende a porta USB.
  3. Dê dois cliques em INICIAR-HYDRASMART.bat

Em cerca de 30 segundos:

  • abrem duas janelas, "HydraSmart API" e "HydraSmart Painel". Não feche essas duas.
  • o navegador abre sozinho em http://localhost:4173;
  • o servidor encontra o Arduino automaticamente e o indicador no menu lateral fica verde.
Na primeira vez, o Firewall do Windows pode pedir permissão para o Node.js. Marque Redes privadas e clique em Permitir. Isso é necessário para mostrar o painel em outro aparelho.

Mostrar o painel numa TV, tablet ou celular

A janela do INICIAR mostra um endereço como http://192.168.0.15:4173. Abra esse endereço em qualquer aparelho conectado à mesma rede Wi-Fi. Todos atualizam em tempo real ao mesmo tempo.

5

Desligar

~5 s

Dê dois cliques em PARAR-HYDRASMART.bat. As leituras gravadas ficam salvas no banco.

Checklist do dia da feira

  • Notebook carregado e na tomada. Desative a suspensão em Configurações → Sistema → Energia.
  • Abrir o Docker Desktop e esperar "Engine running". Se a opção de iniciar com o Windows estiver marcada, ele abre sozinho.
  • Plugar o Arduino, com a IDE do Arduino fechada.
  • Dois cliques em INICIAR-HYDRASMART.bat.
  • Abrir a página Diagnóstico e conferir o autodiagnóstico: API, tempo real, banco e Arduino devem estar com ✔.
  • Testar o som (Diagnóstico → Testar sirene). O navegador só libera som depois do primeiro clique na página.
Plano B: se o Arduino falhar, clique em Modo Real → Trocar no menu lateral. O modo demonstração simula cenários de chuva e alagamento sem gravar nada no histórico.

Atualizar para a versão mais nova

Com o sistema desligado, abra o terminal em C:\HydraSmart e rode:

cd HydraSmartAPI;   git pull;   cd ..
cd HydraSmartFront; git pull;   cd ..

Depois rode INSTALAR-HYDRASMART.bat de novo. Ele mantém o .env e os dados do banco.

Gravar o firmware no Arduino (só se for uma placa nova)

  1. Instale a Arduino IDE: arduino.cc/en/software
  2. Abra HydraSmartAPI\firmware\hydrasmart_firmware.ino.
  3. Em Ferramentas → Placa, escolha Arduino Uno. Em Ferramentas → Porta, escolha a porta COM do Arduino.
  4. Clique em Carregar (seta →).
  5. Feche a IDE antes de iniciar o HydraSmart.

Problemas comuns

SintomaSolução
"Node.js não encontrado" logo após instalarFeche e abra a janela de novo, ou reinicie o computador.
Docker Desktop não abre ou fica em "Starting"Confira a virtualização na BIOS. Rode wsl --update no PowerShell como administrador e reinicie.
"Porta ocupada" ao iniciar o bancoOutro programa usa a porta 5433. No arquivo .env, troque DB_PORT=5434 e a porta em DATABASE_URL para 5434.
Arduino não é encontradoFeche a IDE do Arduino. Troque o cabo (alguns só carregam e não transmitem dados). Instale o driver CH340. Com mais de uma placa, defina SERIAL_PORT=COM4 (a porta certa) no .env.
Bueiros "Desatualizado"O Arduino parou de enviar dados. Confira o cabo. A API reconecta sozinha a cada 5 segundos.
Painel mostra "Servidor indisponível"A janela "HydraSmart API" foi fechada ou mostra um erro. Rode PARAR e depois INICIAR.
Outro aparelho não abre o painelOs dois precisam estar no mesmo Wi-Fi, e o Firewall precisa permitir o Node.js em "Redes privadas".
Banco aparece como "memória" no DiagnósticoO Docker não estava ligado quando a API subiu, e os dados não serão salvos. Abra o Docker, rode PARAR e depois INICIAR.
