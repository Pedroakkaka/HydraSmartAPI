Guia de instalação em outro computador

Como preparar qualquer notebook com Windows para rodar o sistema completo (banco de dados, API, painel e o protótipo físico com duas réguas de eletrodos) e ligá-lo com dois cliques no dia da feira.

Versão do sistema: API v3.3 • Painel v3.2  |  Repositórios: github.com/Pedroakkaka/HydraSmartAPI e HydraSmartFront
1 · Instalar programasGit, Node.js e Docker Desktop (uma vez)
2 · Instalar o sistemagit clone + dois cliques em INSTALAR
3 · UsarDois cliques em INICIAR e PARAR
Faça a instalação com antecedência e com internet. No dia da feira só é preciso ligar o sistema.

O que o notebook precisa ter

ItemMínimo
SistemaWindows 10 (22H2) ou Windows 11, 64 bits
Memória8 GB de RAM (o Docker usa cerca de 2 GB)
Espaço livre10 GB
VirtualizaçãoAtivada na BIOS (quase todos os notebooks já vêm assim)
Porta USBPara o cabo do Arduino
Para conferir a virtualização: abra o Gerenciador de Tarefas → Desempenho → CPU e veja se "Virtualização" mostra Habilitado.

Instalação (uma vez por computador)

1

Instalar os programas

~20 min

Instale nesta ordem, sempre aceitando as opções padrão:

  1. Git — git-scm.com/download/win
  2. Node.js (versão LTS) — nodejs.org
  3. Docker Desktop — docker.com/products/docker-desktop
    • Na instalação, deixe marcado "Use WSL 2" e reinicie o computador quando ele pedir.
    • Abra o Docker Desktop uma vez, aceite os termos e espere "Engine running". O login não é necessário.
    • Recomendado: em Settings → General, marque "Start Docker Desktop when you sign in".
  4. Driver do Arduino, só se a placa usar o chip CH340 (modelos mais baratos): wch-ic.com/downloads/CH341SER_EXE.html
Se o Docker reclamar de WSL: abra o PowerShell como administrador, rode wsl --update e reinicie.
2

Baixar o projeto

~1 min
  1. Crie a pasta C:\HydraSmart.
  2. Clique com o botão direito dentro dela e escolha "Abrir no Terminal".
  3. Rode o comando:
git clone https://github.com/Pedroakkaka/HydraSmartAPI.git

Se o GitHub pedir login, entre com uma conta que tenha acesso aos repositórios. O painel (HydraSmartFront) é baixado sozinho no próximo passo.

3

Instalar o sistema

1 a 5 min

Abra a pasta C:\HydraSmart\HydraSmartAPI e dê dois cliques em:

INSTALAR-HYDRASMART.bat

O instalador faz tudo sozinho:

  • confere se Node, Git e Docker estão instalados;
  • baixa o painel (HydraSmartFront);
  • cria o .env e a chave do operador;
  • instala as dependências;
  • liga o banco de dados e cria as tabelas;
  • gera o painel otimizado e roda os testes.

Estrutura final das pastas:

C:\HydraSmart\
├── HydraSmartAPI\    servidor, banco,
│                     firmware e .bat
└── HydraSmartFront\  painel
No final deve aparecer "Instalação concluída!", junto com a chave do operador.
Se o Windows mostrar "O Windows protegeu o computador", clique em Mais informações → Executar assim mesmo.

O protótipo físico

4

Preparar as réguas de eletrodos

~10 min

Cada bueiro tem uma régua com 6 contatos (pontas de jumper) em alturas diferentes. O nível é a fração de contatos que a água alcança: 3 de 6 = 50%.

BueiroPinos do Arduino (contato de baixo → de cima)Leitura
B01A0 · A1 · A2 · A3 · A4 · A5Analógica
B02D7 · D6 · D5 · D4 · D3 · D2Digital
  • Fio de referência: em cada compartimento, um fio ligado ao GND do Arduino chegando ao fundo, abaixo do contato mais baixo. O ideal é um fio desencapado subindo ao longo de toda a régua.
  • Água com sal: água de torneira com uma pitada de sal medida (cerca de ½ colher de chá por litro). Sem sal, o B02 só detecta o contato de baixo. Água destilada não funciona.
  • Bombas: nunca ligue bombas ou baterias aos pinos do Arduino.
A água salgada corrói as pontas dos contatos. Troque a água ao fim de cada dia de uso.

Gravar o firmware (placa nova ou com outro programa)

  1. Na Arduino IDE (arduino.cc/en/software), abra HydraSmartAPI\firmware\hydrasmart_reguas\hydrasmart_reguas.ino.
  2. Em Ferramentas, escolha a placa Arduino Uno e a porta COM. Clique em Carregar (→).
  3. Confira no Monitor Serial em 115200: devem aparecer linhas como {"bueiro":1,"nivel_pct":50.0,...}.
  4. Feche a IDE antes de iniciar o HydraSmart.
Se a régua não detectar a água, grave firmware\diagnostico_eletrodos: ele mostra o valor de cada contato no Monitor Serial.

Uso no dia a dia

5

Ligar o sistema

~30 s
  1. Ligue o Arduino no USB, com a IDE do Arduino fechada.
  2. Dê dois cliques em INICIAR-HYDRASMART.bat
  • Abrem as janelas "HydraSmart API" e "HydraSmart Painel". Não feche essas duas.
  • O navegador abre em http://localhost:4173, e o servidor encontra o Arduino sozinho.
  • A janela do INICIAR mostra a chave do operador. Anote-a.

Ver as leituras do protótipo

O painel abre em "Análise com dados reais". No menu lateral, clique no botão de modo (Trocar), escolha Projeto físico, digite a chave do operador e confirme. A faixa amarela "MODO PROTÓTIPO EXPERIMENTAL" indica leituras da bancada.

Na instalação local, quem lê a USB é o servidor. O cartão "Conexão USB do Arduino" do painel serve para quando a API está na nuvem; aqui ele daria erro de porta ocupada, então não precisa ser usado.

Mostrar numa TV, tablet ou celular

A janela do INICIAR mostra um endereço como http://192.168.0.15:4173. Abra-o em qualquer aparelho na mesma rede Wi-Fi. Na primeira vez, permita o Node.js no Firewall em Redes privadas.

6

Desligar

~5 s

Dê dois cliques em PARAR-HYDRASMART.bat. Os dados gravados ficam salvos no banco.

Checklist do dia da feira

  • Notebook carregado e na tomada. Desative a suspensão em Configurações → Sistema → Energia.
  • Docker Desktop aberto, com "Engine running".
  • Água nova com sal nos compartimentos e réguas no lugar.
  • Arduino plugado, com a IDE do Arduino fechada.
  • Dois cliques em INICIAR-HYDRASMART.bat e anotar a chave do operador.
  • No painel, trocar para Projeto físico e conferir B01 e B02 mudando quando a água sobe e desce.
  • Abrir Diagnóstico e conferir a "Saúde do monitoramento" e os níveis por bueiro.
  • Se for mostrar os avisos no celular, tocar em Ativar avisos no aparelho.
Plano B: se o Arduino falhar, vá em Bueiros e sensores → Iniciar simulação de teste. A simulação gera níveis sintéticos e não grava nada no histórico.

Atualizar para a versão mais nova

Com o sistema desligado, abra o terminal em C:\HydraSmart e rode:

cd HydraSmartAPI;   git pull;   cd ..
cd HydraSmartFront; git pull;   cd ..

Depois rode INSTALAR-HYDRASMART.bat de novo. Ele mantém o .env e os dados do banco. Se o firmware mudou, grave-o de novo (passo 4).

Problemas comuns

SintomaSolução
"Node.js não encontrado" logo após instalarFeche e abra a janela de novo, ou reinicie o computador.
Docker não abre ou fica em "Starting"Confira a virtualização na BIOS. Rode wsl --update como administrador e reinicie.
"Porta ocupada" ao iniciar o bancoNo .env, troque DB_PORT=5434 e a porta em DATABASE_URL para 5434.
Arduino não é encontradoFeche a IDE do Arduino. Troque o cabo (alguns só carregam). Instale o driver CH340. Com mais de uma placa, defina SERIAL_PORT=COM4 no .env.
Nível sempre em 0%Confira se o firmware hydrasmart_reguas está gravado (Monitor Serial em 115200) e se o fio de GND está na água.
B02 só detecta o contato de baixoFalta sal na água, ou o fio de GND não sobe ao longo da régua.
"CONTATOS_INCONSISTENTES"Confira a ordem dos fios (B02: D7 embaixo, D2 em cima) e se algum jumper encosta no GND fora da água.
"Chave de operador necessária" ou "inválida"Use a chave da janela do INICIAR, ou a linha OPERATOR_API_KEY do arquivo HydraSmartAPI\.env.
"Operações administrativas desabilitadas"Rode PARAR e depois INICIAR: o INICIAR cria a chave sozinho.
Painel mostra "Servidor indisponível"A janela "HydraSmart API" foi fechada ou mostra erro. Rode PARAR e depois INICIAR.
Outro aparelho não abre o painelMesmo Wi-Fi nos dois, e o Firewall permitindo o Node.js em "Redes privadas".
Banco aparece como "memória"O Docker não estava ligado quando a API subiu. Abra o Docker, rode PARAR e depois INICIAR.
